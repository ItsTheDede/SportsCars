# SportsCars

Projeto desenvolvido em contexto de sala de aula utilizando ASP.NET MVC.

## Conteúdo
* **Personalização de Veículos** - Configuração de componentes e estilos dos carros
* **Modelos 3D** - Visualização e interação com os modelos tridimensionais dos veículos
* **Estrutura MVC** - Organização do projeto através de Models, Views e Controllers

## Objetivo
Desenvolver uma aplicação web interativa em ASP.NET MVC para personalização e visualização 3D de carros desportivos.
